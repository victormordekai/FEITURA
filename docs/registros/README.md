# Registros FEITURA | Gate 1

Este diretório é reservado para registros de rastreabilidade dos romaneios FEITURA.

No Gate 1, a publicação estática em GitHub Pages não possui permissão para escrever automaticamente neste diretório. O navegador pode gerar o registro JSON, mas a persistência no repositório exige uma ação externa de escrita.

O formato preparado pelo Gate 1.1 é compatível com futura ingestão por Apps Script, Python ou backend próprio.

Não colocar neste diretório arquivos contendo dados pessoais sem uma política de tratamento, controle de acesso, retenção e exclusão definida.

# FEITURA — Direção UX

## 01. O que o usuário deve compreender em poucos segundos

FEITURA é um lugar para transformar uma necessidade de produção em uma conversa produtiva concreta.

Dois caminhos são prioritários:

### Preciso produzir
Empresa, marca, desenvolvimento ou comprador.

Entrada:
produto → quantidade → processos → prazo/disponibilidade → referência de valor.

Saída:
estimativa → estrutura produtiva → capacidade compatível → contato.

### Posso produzir
Costureira, facção, modelista ou parceiro produtivo.

Entrada:
produto → processos → horas disponíveis → renda desejada → localização.

Saída:
capacidade produtiva → referência econômica → oportunidades compatíveis → contato.

## 02. O que não deve aparecer como requisito

O usuário não precisa:

- entender RETEAR;
- conhecer conceitos de BPM, Lean ou governança;
- aprender terminologia tecnológica;
- interpretar um “ecossistema” antes de usar a ferramenta;
- acreditar em uma causa ou manifesto.

A complexidade pertence à infraestrutura.

## 03. Personalidade

FEITURA deve parecer:

- precisa;
- humana;
- editorial;
- produtiva;
- autoral;
- confiável;
- contemporânea;
- material sem ser artesanal;
- tecnológica sem parecer software genérico.

FEITURA não deve parecer:

- marketplace genérico;
- SaaS corporativo;
- rede social;
- feira de artesanato;
- ONG;
- plataforma “AI-first”;
- catálogo frio de prestadores.

## 04. PoPL

A função PoPL aparece como comportamento do produto, não como slogan.

O sistema aproxima:

DEMANDA ↔ CAPACIDADE

e estrutura o encontro por:

PRODUTO + PROCESSO + TEMPO + QUANTIDADE + VALOR + LOCALIZAÇÃO.

## 05. Neoestética

Referências sem reprodução literal:

- fichas técnicas;
- etiquetas de produção;
- papel editorial;
- margens de catálogo;
- anotações de oficina;
- marcações de modelagem;
- linhas de construção;
- tecido como textura;
- tipografia de publicação;
- números de ordem;
- índices e registros.

A referência deve ser percebida como sistema visual, não como fantasia de costura.

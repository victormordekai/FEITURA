# FEITURA — Design System

## Paleta

- `paper`: marfim quente, base editorial.
- `paper-deep`: papel envelhecido muito sutil.
- `ink`: quase preto, texto.
- `muted`: cinza quente.
- `olive`: verde oliva profundo, ligação material com RETEAR sem copiar sua aparência.
- `clay`: terracota discreta para estados de ação.
- `line`: linhas de arquivo.
- `white`: superfícies claras.

## Tipografia

- Identidade / wordmark: Feitura Display Prototype Regular, exclusiva para o logotipo FEITURA®.
- Display editorial: Libre Baskerville.
- Interface e corpo: DM Sans, preservada como tipografia principal do HTML.
- Dados: DM Mono para valores, processos e identificadores.

A fonte identitária não deve ser aplicada ao corpo, formulários, navegação ou componentes de interface.

## Forma

Evitar cards excessivamente arredondados.

Preferir:

- retângulos editoriais;
- bordas finas;
- blocos assimétricos;
- números grandes;
- linhas de registro;
- etiquetas pequenas;
- sobreposição controlada;
- espaços amplos.

## Imagem

A V1 usa placeholders visuais CSS e áreas de imagem preparadas para fotografia documental.

Quando fotografias forem inseridas, priorizar:

- mãos trabalhando;
- máquinas e ferramentas;
- mesa de corte;
- tecido em uso;
- peças em construção;
- ambientes produtivos reais.

Evitar fotografia de “artesanato instagramável”.

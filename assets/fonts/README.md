# FEITURA | Tipografia identitária

`feitura-fonte.otf` contém a fonte **Feitura Display Prototype Regular**, utilizada exclusivamente para a identidade tipográfica do logotipo FEITURA®.

A fonte não substitui a tipografia de interface do projeto.

Sistema de interface preservado:
- DM Sans: corpo, navegação e controles.
- DM Mono: dados, índices e identificadores.
- Libre Baskerville: títulos editoriais.

A fonte identitária é carregada localmente apenas para ocorrências de wordmark/logo no frontend.
